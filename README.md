Developer: Ana Quintero
Language: Python 

Application for the chair of Medicine in the Ruhr-Universität Bochum. Presented to read the data, plot in 3D, on each plane, scatters with the FWHM and comparision of files. 

The GUI is made in QT Creator. Files of principalwinow.ui, scatterwindow.ui, pop_up_scatter.ui, fwhm.ui and compaData.ui were made on Qt creator for the visual options of the App. Final_version.py contains all the application logic. 

The .spec file is for the creation of the executable app. NO modify!
